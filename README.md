# How Are You Feeling

A tiny, local-only mental-health check-in app built with Expo + React Native.

## Run locally

```bash
npm install
npx expo start
```

## Build an installable Android APK (EAS)

```bash
eas build -p android --profile preview
```

You need an Expo account to run EAS Build.

## iOS note

The codebase supports iOS builds, but iOS distribution/signing setup is intentionally deferred in this version.
